# Security Policy

## Scope

This policy covers the mcp-hub repository, the live site at
https://mcp.gholl.com, and the MCP endpoint serving MCP Apps UI tools over
Streamable HTTP at https://mcp.gholl.com/mcp.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

mcp-hub is currently at 0.1.0. Security fixes are applied to the latest 0.1.x
release only; older or unsupported versions do not receive patches.

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities. Report them privately
through either channel:

- GitHub Security Advisories: https://github.com/Gholls/mcp-hub/security/advisories/new
- Email: gholl@gholl.com

Please include a description of the vulnerability, the affected endpoint or
tool, steps to reproduce, and the potential impact.

## Response Timeline

- Reports are acknowledged within 72 hours.
- An initial assessment, including severity and a fix or mitigation plan, is
  completed within 7 days.

Please avoid public disclosure until a fix has been released.
